# ADR-0002：第一阶段采用 FFF 材料挤出工艺

- **状态**：已接受（项目参考工艺范围；工艺窗口与实物可行性仍待验证）
- **日期**：2026-11-04
- **决策人/批准依据**：项目用户已明确批准 FDM/FFF 初始参考规格；本 ADR 记录该批准范围及路线比较依据
- **关联需求**：FR-004、FR-005、FR-007、FR-011；NFR-002、NFR-003、NFR-005
- **关联来源**：[SRC-0001](../sources/register.md#src-0001-第一阶段参考打印机初始规格确认)、[SRC-0002](../sources/register.md#src-0002-iso-17296-22015-工艺类别与原料概览)、[SRC-0003](../sources/register.md#src-0003-nist-additive-manufacturing-technologies)、[SRC-0004](../sources/register.md#src-0004-fdm---fused-deposition-modeling-what-is-it)、[SRC-0005](../sources/register.md#src-0005-instructions-for-resin-sla-3d-printing)、[SRC-0006](../sources/register.md#src-0006-powder-bed-fusion-how-does-it-work)
- **背景与问题**：第一阶段需要选定一个能支撑机械、电气、固件、主机和 SIL 仿真的具体成形工艺。用户已确认 FDM/FFF、PLA 长丝、1.75 mm 进料和 0.4 mm 喷嘴。
- **候选方案**：
  1. FFF 材料挤出；
  2. SLA/DLP 槽式光聚合；
  3. PBF 粉末床熔融；
  4. 其他增材制造类别。
- **约束条件**：与用户批准的参考规格一致；优先实现可复现的软件在环闭环；不将仿真等同实物验证；不在缺少来源时冻结工艺参数。
- **权衡分析**：FFF 的长丝送料、加热喷嘴和 G-code 路径沉积机制直接匹配已批准规格，并使运动、挤出和温控控制对象可在一个参考系统中集成。SLA 使用液态光敏树脂和光固化，并有独立清洗/后固化流程；PBF 使用粉末床与能量束/热源，其设备和过程对象与长丝挤出路线不同。其他类别需要另行建立不同过程模型。详见 [技术路线比较](../phase1/architecture/technology-route-assessment.md)。
- **决策**：第一阶段采用 FFF（材料挤出）作为参考成形工艺；参考材料为 PLA、长丝规格 1.75 mm、单挤出机、单热端、0.4 mm 喷嘴。运动结构仍按 ADR-0001 的 Cartesian 床身移动式参考范围管理。
- **决策理由**：与用户批准规格一致，且为本项目需要覆盖的运动、挤出、温控、G-code 和任务状态提供连贯的 SIL 建模对象。
- **风险与代价**：本决策不冻结温度、速度、加速度、流量、层高、线宽、步距、精度或电气额定值；也不证明床身移动式结构满足目标动态性能。简化仿真模型不能证明真实设备安全或打印质量。
- **验证计划**：在后续节点定义 G-code 子集、运动学/挤出模型、热模型和故障注入场景；参数来源和模型保真度需记录；SIL 验收后如需实物验证，另行制定安全计划并取得授权。
- **复核触发条件**：用户修改工艺/材料；路线比较所依据的需求变化；机械或热设计证明该路线无法满足已批准空间；或关键 SIL 验收场景无法合理建模。
