# 架构决策记录（ADR）目录与模板

> ADR 记录影响系统边界、接口、选型、安全和长期维护的关键决策。决策可为“已接受”“暂定”“已取代”或“拒绝”。

## 状态定义

- **提议中**：正在收集选项和证据。
- **已接受**：决策已获授权，且适用范围清晰；不代表相关工程验证已通过。
- **暂定**：为推进工作采用的临时方案，必须有复核条件。
- **已取代**：被后续 ADR 替代，保留历史。
- **拒绝**：经过评估后不采用，保留理由。
