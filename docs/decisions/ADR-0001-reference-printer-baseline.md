# ADR-0001：第一阶段参考打印机范围基线

- **状态**：已接受（项目范围基线；工程可行性仍待验证）
- **日期**：2026-11-04
- **决策人/批准依据**：项目用户明确确认初始参考规格；来源记录 SRC-0001
- **关联需求**：第一阶段需求基线第 2 节；FR-004、FR-005、FR-007、FR-011
- **关联来源**：[SRC-0001](../sources/register.md#src-0001-第一阶段参考打印机初始规格确认)
- **背景与问题**：需要统一第一阶段的参考打印机范围，避免机械、电气、固件、主机软件和仿真各自采用不同假设。
- **候选方案**：
  1. 采用用户确认的桌面 FDM/FFF Cartesian 床身移动式参考规格。
  2. 暂不指定具体参考打印机规格，仅实现通用可配置打印机仿真。
  3. 采用其他运动学或成形工艺路线（尚未进行完整技术比较）。
- **约束条件**：第一阶段优先完成可复现的完整 SIL 软件闭环；不以真实硬件作为初始交付前提；不得把仿真结果等同实物验证。
- **权衡分析**：方案 1 给机械尺寸、轴模型、挤出和 G-code 场景提供共同目标；方案 2 更通用但难以形成可验收的具体参考系统；方案 3 需要额外路线比较，超出当前已批准范围。
- **决策**：采用 FDM/FFF；Cartesian，优先床身移动式；有效打印空间 220 × 220 × 250 mm；PLA 1.75 mm；0.4 mm 喷嘴；单喷头单挤出机；首要目标为完整软件系统通过 SIL 仿真。
- **决策理由**：以上规格由用户明确批准，作为项目范围输入。
- **风险与代价**：该决策不是工程可行性结论；结构细节、速度/加速度、精度、热设计、器件型号、成本和安全设计仍须研究。若约束冲突，应通过变更记录重新评估。
- **验证计划**：在需求/架构、机械、电气和仿真章节分别验证尺寸可达性、运动学一致性、接口能力、PLA 热模型边界及端到端 SIL 验收。
- **复核触发条件**：发现无法满足 220 × 220 × 250 mm 工作空间、Bed-slinger 结构与性能目标冲突、关键器件/安全约束不满足，或用户提出范围变更。
- **相关 ADR**：暂无。
