# 项目术语表

| 术语 | 英文/缩写 | 项目内定义 |
|---|---|---|
| 增材制造 | Additive Manufacturing (AM) | 通过逐层或逐体素添加材料形成零件的制造方法总称。 |
| 熔融沉积成形 | Fused Deposition Modeling (FDM) | 常用于热塑性材料挤出的工艺称谓；商标使用应遵循权利人规则。 |
| 熔融长丝制造 | Fused Filament Fabrication (FFF) | 以热塑性长丝熔融挤出并逐层沉积的工艺。本项目第一阶段参考工艺。 |
| 软件在环 | Software-in-the-Loop (SIL) | 在仿真环境中运行待测软件，以虚拟对象/外设替代真实硬件。 |
| 硬件在环 | Hardware-in-the-Loop (HIL) | 将真实控制硬件接入实时或等效仿真对象；不等同纯软件仿真。 |
| 笛卡尔运动学 | Cartesian kinematics | 以相互正交的线性轴描述运动的运动学形式。 |
| 床身移动式 | Bed-slinger | 打印床沿一个或多个轴移动的机构类别；具体轴配置以机械设计为准。 |
| G-code | G-code | 用于描述数控运动、过程和辅助命令的指令语言/方言集合；需明确支持子集。 |
| 主机软件 | Host software | 运行在上位计算平台，负责任务管理、设备通信、用户交互等的软件。 |
| 固件 | Firmware | 运行在控制器上的软件，负责实时设备控制及相关状态管理。 |
| 板级支持包 | Board Support Package (BSP) | 针对特定硬件板卡提供启动、时钟、外设和板级配置的软件层。 |
| 硬件抽象层 | Hardware Abstraction Layer (HAL) | 将上层控制逻辑与具体外设实现隔离的接口层。 |
| 运动规划 | Motion planning | 将目标路径/速度约束转化为满足运动学与动态约束的可执行运动轨迹。 |
| 归零 | Homing | 通过参考传感器/限位建立机器坐标参考位置的过程。 |
| 软限位 | Soft limit | 软件根据已知坐标边界限制运动命令；不能替代硬件限位或急停。 |
| 热失控 | Thermal runaway | 加热系统在控制或测量异常时持续升温或无法按预期受控的危险状态。 |
| 接口控制文档 | Interface Control Document (ICD) | 定义组件间协议、信号、数据结构、时序和错误处理的受控文档。 |
| 架构决策记录 | Architecture Decision Record (ADR) | 记录关键架构问题、候选方案、权衡、决策和后续复核条件的文档。 |
| 单一事实源 | Single Source of Truth (SSOT) | 对某类事实指定唯一权威维护位置，其他文档引用而非复制维护。 |
| 待确认 | TBD | 信息尚未确定；不得被解释为默认值或零值。 |
| 待核实 | To Be Verified (TBV) | 已提出但尚缺足够证据验证的事实或结论。 |

## 术语维护规则

新增术语时先搜索本表；若存在近义词，优先沿用已有定义。术语含义发生变化时记录变更日期和影响文档，不静默改写既有接口语义。
