# 03 电气与硬件平台

## 节点 03-01：电源树与电气安全架构
- **状态**：未完成
- **必须完成**：定义输入电源、逻辑/电机/加热负载电源树、保险、接地、线径、连接器、隔离、过流/过压/反接和热保护需求。
- **禁止事项**：无额定值与保护设计时给出可直接接线的高压方案。
- **前置依赖**：01-02、01-05。
- **交付物**：电源树、电气安全需求、线束接口表。
- **验收标准**：各负载功率预算、保护策略和验证方法可审查。

## 节点 03-02：控制板与 MCU/SOC 选型
- **状态**：未完成
- **必须完成**：比较 MCU/SOC 的算力、定时器、PWM、ADC、DMA、通信接口、实时性、存储、生态、生命周期、成本与仿真支持；评估自研板与现成控制板。
- **禁止事项**：将单一厂商宣传指标视为完整选型结论。
- **前置依赖**：01-03、03-01。
- **交付物**：候选器件矩阵、控制板架构和 ADR。
- **验收标准**：需求逐项映射至器件资源；供货与生命周期状态注明来源和日期。

## 节点 03-03：步进驱动、电机与传感器
- **状态**：未完成
- **必须完成**：比较步进/伺服方案、驱动器、编码器、限位、探针、热敏电阻/RTD/热电偶、风扇和电流检测。
- **禁止事项**：忽略电气兼容、热设计、EMI 和故障检测。
- **前置依赖**：02-01、03-02。
- **交付物**：接口矩阵、候选 BOM、驱动控制需求。
- **验收标准**：信号、电压、电流、精度、采样和失效模式均有定义。

## 节点 03-04：原理图、PCB 与线束
- **状态**：未完成
- **必须完成**：形成原理图模块、PCB 约束、连接器/线束定义、测试点和可制造性审查清单。
- **禁止事项**：未审查原理图/布局即宣称可投板。
- **前置依赖**：03-01 至 03-03。
- **交付物**：原理图、PCB 设计资料、线束图、BOM。
- **验收标准**：ERC/DRC、功率/热/间距审查及版本记录齐全。
