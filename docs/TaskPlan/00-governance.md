# 00 项目治理与知识库规范

全局约束见根目录 [TaskPlan.md](../../TaskPlan.md)。

## 节点 00-01：仓库初始化与现状审计
- **状态**：已完成
- **必须完成**：
  - 确认仓库地址、默认分支、访问权限及仓库初始状态。
  - 审计已有文件、提交历史、许可证和现有约定；空仓库须明确记录。
  - 建立根目录 TaskPlan、章节计划目录和 README 导航。
  - 记录初始化提交并回读验证。
- **禁止事项**：未审计前覆盖已有文件；把空仓库初始化描述为已有代码审查。
- **前置依赖**：无。
- **交付物**：根 TaskPlan.md、README.md、docs/TaskPlan/ 章节计划。
- **验收标准**：仓库元数据和权限已确认；文件结构已建立；提交可读取；根计划与章节索引一致。

## 节点 00-02：第一阶段范围基线与需求模板
- **状态**：正在进行中
- **当前进展**：已建立第一阶段需求基线草案，明确暂定 FDM/FFF 路线、功能需求、非功能需求、仿真验收场景和待确认事项。
- **阶段交付物**：[第一阶段需求基线（草案）](../phase1/requirements/requirements-baseline.md)
- **必须完成**：定义用户场景、打印尺寸、材料、速度/精度目标、成本/复杂度边界、仿真目标、接口约束和非目标；建立需求 ID、优先级、来源、验收方法模板。
- **禁止事项**：无用户输入/证据时冻结具体打印尺寸、性能或成本数字。
- **前置依赖**：00-01。
- **交付物**：需求基线、假设清单、需求追踪模板。
- **验收标准**：每项需求可追溯至来源并具有可测试验收方法；未决项显式列出。

## 节点 00-03：来源、证据与引用规范
- **状态**：未完成
- **必须完成**：建立来源登记字段（标题、机构/作者、版本/日期、URL、访问日期、证据类型、支持结论、可信度/限制）；区分官方规格、标准原文、论文、社区经验和推断。
- **禁止事项**：无来源的关键参数与标准断言。
- **前置依赖**：00-01。
- **交付物**：来源登记规范及来源台账模板。
- **验收标准**：关键技术决策和外部事实可回溯至具体来源。

## 节点 00-04：决策、风险与变更管理
- **状态**：未完成
- **必须完成**：建立 ADR、风险登记、问题/假设清单、变更记录模板；覆盖热失控、运动碰撞、电气安全、固件失效、许可证和供应链风险。
- **禁止事项**：将暂定方案当成已批准方案。
- **前置依赖**：00-02、00-03。
- **交付物**：决策记录模板、风险登记表。
- **验收标准**：关键选择有候选、约束、权衡、决定人/时间和验证计划。

## 节点 00-05：知识库导航与维护流程
- **状态**：未完成
- **必须完成**：定义目录、文件命名、术语、图表、代码示例、版本更新和过期内容复核规则。
- **禁止事项**：重复建设互相矛盾的事实源。
- **前置依赖**：00-01。
- **交付物**：知识库写作规范和导航。
