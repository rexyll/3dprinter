# 06 主机、切片与 App 软件

## 节点 06-01：设备通信协议与主机服务
- **状态**：未完成
- **必须完成**：定义 USB/串口/网络传输、消息 framing、请求响应、事件、超时、重连、版本协商和权限。
- **禁止事项**：无认证/校验的远程危险控制接口。
- **前置依赖**：01-03、05-01。
- **交付物**：协议规范、主机服务原型。
- **验收标准**：断连、重连、乱序/损坏数据及版本不匹配有明确处理。

## 节点 06-02：打印任务、文件与设备管理
- **状态**：未完成
- **必须完成**：实现任务队列、文件校验、任务状态、进度、暂停/取消、配置管理和日志导出。
- **禁止事项**：不校验来源/完整性的文件直接执行。
- **前置依赖**：06-01、05-05。
- **交付物**：主机任务管理模块和 API。
- **验收标准**：任务生命周期和失败恢复可自动化测试。

## 节点 06-03：切片器与模型工作流
- **状态**：未完成
- **必须完成**：评估 STL/3MF 等输入、切片器集成、材料/机器配置、G-code 输出和版本兼容。
- **禁止事项**：未经验证宣称完全兼容某切片器或格式。
- **前置依赖**：01-02、05-05。
- **交付物**：切片工作流说明、配置模板、兼容性测试。
- **验收标准**：样例模型可生成符合固件命令子集的 G-code。

## 节点 06-04：桌面/Web/App 用户界面
- **状态**：未完成
- **必须完成**：规划设备配对、状态监控、手动移动、温度显示、任务控制、文件管理、告警和用户权限。
- **禁止事项**：将危险动作隐藏在无确认的 UI 操作中。
- **前置依赖**：06-01、06-02。
- **交付物**：交互原型、UI 实现和可访问性检查。
- **验收标准**：核心操作可用性测试通过，危险操作有防误触机制。

## 节点 06-05：升级、配置备份与安全
- **状态**：未完成
- **必须完成**：定义版本兼容、升级签名/完整性、回滚、配置备份恢复、凭据保护和安全更新策略。
- **禁止事项**：无校验固件升级或明文存储敏感凭据。
- **前置依赖**：06-01、06-02、04-01。
- **交付物**：升级与安全设计。
- **验收标准**：升级失败恢复和版本不兼容场景通过测试。
