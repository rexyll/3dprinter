# 01 需求与系统架构

## 节点 01-01：目标场景与参考打印技术路线
- **状态**：已完成
- **完成记录**：已依据 ISO 17296-2、NIST 工艺概览及工艺技术资料，对 FFF 材料挤出、SLA/DLP 槽式光聚合、PBF 粉末床熔融及其他工艺类别进行定性比较；结合用户已批准的 PLA 长丝、1.75 mm 进料、0.4 mm 喷嘴、单挤出机和 SIL 优先目标，确认第一阶段参考工艺为 FFF 材料挤出。已建立 ADR-0002，并明确成本/性能不作无依据数值比较、工艺窗口和实物可行性仍待后续验证。
- **必须完成**：比较 FDM/FFF 与其他路线对本项目目标、复杂度、成本、可仿真性和软件控制范围的影响；提出参考路线但保留决策证据。
- **禁止事项**：在需求未知时声称某路线必然最优；不得把定性工程判断包装为标准结论或实测数据。
- **前置依赖**：00-02、00-03。
- **交付物**：[技术路线比较](../phase1/architecture/technology-route-assessment.md)、[ADR-0002](../decisions/ADR-0002-fff-material-extrusion.md)、来源记录 SRC-0002 至 SRC-0006。
- **验收标准**：路线选择有可追溯的需求映射、权衡、风险和来源；项目决定有 ADR 记录；结论适用边界和未决参数明确。已回读检查交付物及引用。
