# 01 需求与系统架构

## 节点 01-01：目标场景与参考打印技术路线
- **状态**：已完成
- **完成记录**：已依据 ISO 17296-2、NIST 工艺概览及工艺技术资料，对 FFF 材料挤出、SLA/DLP 槽式光聚合、PBF 粉末床熔融及其他工艺类别进行定性比较；结合用户已批准的 PLA 长丝、1.75 mm 进料、0.4 mm 喷嘴、单挤出机和 SIL 优先目标，确认第一阶段参考工艺为 FFF 材料挤出。已建立 ADR-0002，并明确成本/性能不作无依据数值比较、工艺窗口和实物可行性仍待后续验证。
- **必须完成**：比较 FDM/FFF 与其他路线对本项目目标、复杂度、成本、可仿真性和软件控制范围的影响；提出参考路线但保留决策证据。
- **禁止事项**：在需求未知时声称某路线必然最优；不得把定性工程判断包装为标准结论或实测数据。
- **前置依赖**：00-02、00-03。
- **交付物**：[技术路线比较](../phase1/architecture/technology-route-assessment.md)、[ADR-0002](../decisions/ADR-0002-fff-material-extrusion.md)、来源记录 SRC-0002 至 SRC-0006。
- **验收标准**：路线选择有可追溯的需求映射、权衡、风险和来源；项目决定有 ADR 记录；结论适用边界和未决参数明确。已回读检查交付物及引用。

## 节点 01-02：系统需求与验收指标
- **状态**：已完成
- **完成记录**：建立系统需求规格 v0.1，定义系统边界、15 项 SYS 级行为需求、任务生命周期及状态一致性要求、故障响应边界、8 项非功能验收要求、14 项 SIL 场景和 FR/NFR → SYS → SIL 追踪关系。所有未冻结参数均列出后续关闭节点；已更新需求基线、文档导航和根 README，并从 GitHub 回读验证。
- **必须完成**：定义功能/非功能需求：成形空间、运动轴、材料、分辨率、速度、温控、连接、可维护性、可扩展性和仿真保真度；为每项需求明确优先级、来源、验证方法和可观察结果。
- **禁止事项**：编造性能数据；混淆目标值与实测值；把仿真模型参数冒充真实设备额定值。
- **前置依赖**：01-01。
- **交付物**：[系统需求规格与 SIL 验收追踪](../phase1/requirements/system-requirements.md)、[项目需求基线](../phase1/requirements/requirements-baseline.md)。
- **验收标准**：每条需求有唯一 ID、优先级、来源/依据、验证方法和状态；P0 SIL 场景映射到需求和测试；待定性能参数有明确关闭路径。已检查追踪矩阵、链接和未决参数表。

## 节点 01-03：系统分层与接口架构
- **状态**：正在进行中
- **当前进展**：已建立系统逻辑分层、主机至固件至虚拟设备的控制/反馈数据流、SIL 闭环、时序域与同步边界、故障隔离表；已建立 IF-001 至 IF-009 逻辑接口契约、通用消息字段和错误类别草案，并绘制系统上下文图。本轮新增 SYS-001～SYS-015、SIL-001～SIL-014 到逻辑组件及 IF-001～IF-009 的追踪矩阵；ICD 补充请求确认/执行结果区分、标识顺序/重复、单位/坐标、超时/重连、任务安全责任及遥测新鲜度契约。追踪覆盖属于设计审查，不代表实现或测试通过。坐标系/轴方向、幂等细则、重连同步、暂停/取消安全语义、命令确认边界、模型保真度及数值时序预算仍待关闭。
- **必须完成**：绘制机械、电气、MCU/BSP、固件、主机服务、切片器、App、仿真和 CI 分层；定义数据流、控制流、时序和故障边界。
- **禁止事项**：在接口未定义时并行实现互不兼容模块。
- **前置依赖**：01-02。
- **交付物**：[系统逻辑架构](../phase1/architecture/system-architecture.md)、[系统上下文图](../phase1/architecture/system-context.mmd)、[接口控制文档 ICD](../phase1/architecture/interface-control.md)、[需求—组件—接口追踪矩阵](../phase1/architecture/requirements-component-interface-trace.md)。
- **验收标准**：逻辑模块边界、接口提供方/使用方、数据与控制流、时序域、故障责任及错误语义明确；SYS/SIL 到组件/接口追踪无未映射项；接口关键语义缺口均有明确责任节点与证据关闭路径；具体传输协议和部署技术由 01-04 决策并回填 ICD。当前追踪表已完成，但多个接口语义仍待冻结，故节点继续进行中。

## 节点 01-05：系统安全概念与威胁分析

- **必须完成**：识别热、运动、电气、通信、更新和用户操作风险，定义安全状态、急停、联锁、故障响应和仿真测试边界。
- **禁止事项**：把仿真安全结论等同实机认证。
- **前置依赖**：01-02、01-03。
- **交付物**：初步危害分析、系统安全需求。
- **验收标准**：每个高风险危险源有缓解措施和验证计划。
