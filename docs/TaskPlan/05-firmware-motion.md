# 05 打印机固件与运动控制

## 节点 05-01：固件状态机与配置
- **状态**：未完成
- **必须完成**：定义启动、未连接、就绪、归零、打印、暂停、恢复、完成、故障等状态；建立配置校验和持久化。
- **禁止事项**：非法状态转换或未校验配置进入执行路径。
- **前置依赖**：01-03、04-03。
- **交付物**：状态机、配置 schema、状态转换测试。
- **验收标准**：状态转换完整，异常输入安全失败。

## 节点 05-02：运动学、步进调度与加速度规划
- **状态**：未完成
- **必须完成**：实现坐标变换、步进脉冲生成、速度/加速度/jerk 或等效规划、运动队列、挤出同步和软限位。
- **禁止事项**：在未验证边界/限位前允许越界动作。
- **前置依赖**：02-01、03-03、04-02。
- **交付物**：运动规划模块和轨迹测试集。
- **验收标准**：轨迹、时序、边界和数值误差测试通过。

## 节点 05-03：归零、探针与运动校准
- **状态**：未完成
- **必须完成**：实现归零流程、限位/探针去抖、坐标偏移、步距校准接口和故障检测。
- **禁止事项**：将未验证传感器状态作为安全归零依据。
- **前置依赖**：05-02。
- **交付物**：归零模块、仿真场景和校准文档。
- **验收标准**：正常、断线、卡死、反向和超时场景均有测试。

## 节点 05-04：温控、挤出与打印过程控制
- **状态**：未完成
- **必须完成**：实现温度采样滤波、PID/控制策略、挤出控制、风扇控制、预热/冷却和热失控保护逻辑。
- **禁止事项**：绕过温度合理性、加热超时和热失控检测。
- **前置依赖**：03-03、04-02、05-01。
- **交付物**：温控/挤出模块、故障注入测试。
- **验收标准**：断线、短路、升温失败、过温和传感器异常均进入安全状态。

## 节点 05-05：G-code 解析与命令执行
- **状态**：未完成
- **必须完成**：定义支持的 G/M 命令子集、参数校验、缓冲、错误响应、暂停/恢复和兼容性策略。
- **禁止事项**：静默忽略影响运动/温控安全的未知命令。
- **前置依赖**：05-01 至 05-04。
- **交付物**：解析器、命令参考、测试语料。
- **验收标准**：有效/无效/边界/恶意输入测试通过。
