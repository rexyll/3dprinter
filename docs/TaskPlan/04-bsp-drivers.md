# 04 BSP、驱动与嵌入式基础

## 节点 04-01：启动链与构建环境
- **状态**：未完成
- **必须完成**：选择裸机/RTOS/Linux 路线，建立工具链、构建系统、Bootloader/启动流程、链接脚本、固件镜像和版本标识。
- **禁止事项**：混用未经验证的工具链版本。
- **前置依赖**：01-04、03-02。
- **交付物**：可复现构建环境和最小启动固件。
- **验收标准**：干净环境可构建；启动日志/仿真启动可验证。

## 节点 04-02：HAL、BSP 与外设驱动
- **状态**：未完成
- **必须完成**：实现 GPIO、定时器、PWM、ADC、DMA、UART、USB/CAN/Ethernet 等所需接口的抽象与驱动。
- **禁止事项**：无错误处理和超时的阻塞式驱动成为关键控制路径。
- **前置依赖**：04-01、03-03。
- **交付物**：HAL/BSP、驱动 API、虚拟驱动接口。
- **验收标准**：硬件/仿真后端共享上层接口，驱动有单元测试或硬件在环计划。

## 节点 04-03：实时调度、日志与诊断
- **状态**：未完成
- **必须完成**：定义任务优先级、时钟、同步、消息队列、看门狗、日志、故障码和诊断接口。
- **禁止事项**：让日志或低优先级任务破坏运动实时性。
- **前置依赖**：04-01、04-02。
- **交付物**：调度设计、诊断规范和测试。
- **验收标准**：关键时序预算与故障恢复行为可测。
