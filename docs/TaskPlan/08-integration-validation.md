# 08 集成、验证与发布

## 节点 08-01：构建、测试与持续集成
- **状态**：未完成
- **必须完成**：建立格式/lint、静态分析、单元测试、集成测试、仿真回归和制品归档流水线。
- **禁止事项**：以 CI 绿灯替代系统级验收。
- **前置依赖**：04-01、05-01、06-01、07-01。
- **交付物**：CI 配置、测试报告和构建说明。
- **验收标准**：干净环境可重复构建，失败可定位。

## 节点 08-02：端到端打印工作流
- **状态**：未完成
- **必须完成**：从模型/样例 G-code 输入开始，完成解析、任务下发、运动/挤出/温控模拟、状态反馈、暂停/恢复和结束。
- **禁止事项**：跳过真实链路接口而仅用单体演示冒充端到端。
- **前置依赖**：05-05、06-02、07-04。
- **交付物**：E2E 测试、录屏/日志/报告。
- **验收标准**：核心场景重复运行通过，结果和环境可复现。

## 节点 08-03：安全、故障注入与恢复验证
- **状态**：未完成
- **必须完成**：覆盖传感器断线/短路、温升失败、过温、限位失效、通信中断、看门狗、配置损坏和升级失败。
- **禁止事项**：以模拟故障通过推断真实硬件保护性能。
- **前置依赖**：01-05、05-03、05-04、06-05、07-04。
- **交付物**：故障矩阵、测试结果和未解决风险清单。
- **验收标准**：危险状态进入定义的安全状态；残余风险明确。

## 节点 08-04：性能、可维护性与发布验收
- **状态**：未完成
- **必须完成**：测量仿真吞吐、控制周期、响应延迟、资源占用、稳定性和可复现性；完成文档、版本和发布包。
- **禁止事项**：将仿真性能等同实机性能。
- **前置依赖**：08-01 至 08-03。
- **交付物**：第一阶段验收报告、版本发布说明。
- **验收标准**：根 TaskPlan 第一阶段门禁全部满足并由证据支持；否则保持进行中。
