# 02 机械系统

## 节点 02-01：运动学与机构路线
- **状态**：未完成
- **必须完成**：比较 Cartesian、CoreXY、Delta、床动/床固定等结构；建立坐标系、自由度、运动范围和约束。
- **禁止事项**：无计算/来源地宣称速度、刚度或精度优势。
- **前置依赖**：01-02、01-03。
- **交付物**：机构比较、运动学模型和 ADR。
- **验收标准**：坐标约定、轴映射和运动边界可计算、可测试。

## 节点 02-02：机架、导向与传动系统
- **状态**：未完成
- **必须完成**：研究机架型材/板件、直线导轨/滚轮、皮带/丝杆、联轴器、轴承、张紧和紧固件；完成载荷、刚度、间隙与装配分析。
- **禁止事项**：将未经计算的尺寸作为制造图。
- **前置依赖**：02-01。
- **交付物**：结构方案、BOM 草案、CAD/仿真模型。
- **验收标准**：装配关系、行程、干涉和关键载荷假设有证据。

## 节点 02-03：挤出机、热端、热床与冷却
- **状态**：未完成
- **必须完成**：梳理直驱/远程挤出、热端、喷嘴、热床、散热器、风道、风扇和温度传感器接口。
- **禁止事项**：忽略热隔离、材料温度限制和热失控风险。
- **前置依赖**：01-02、03-02。
- **交付物**：挤出与热管理设计、接口规格。
- **验收标准**：热/机械边界、安装接口和风险控制清楚。

## 节点 02-04：装配、公差、维护与制造
- **状态**：未完成
- **必须完成**：定义基准、公差链、装配顺序、线缆拖链、维护空间、可替换部件和制造工艺。
- **禁止事项**：把概念模型当作可直接制造的工程图。
- **前置依赖**：02-02、02-03。
- **交付物**：装配说明、制造图纸清单、维护计划。
- **验收标准**：关键装配和维护步骤可复现。
