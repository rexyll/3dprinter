# 07 仿真与虚拟硬件

## 节点 07-01：仿真需求与平台选择
- **状态**：未完成
- **必须完成**：比较软件在环、硬件在环、机械运动学/动力学、热模型和系统级仿真平台；定义仿真保真度与速度目标。
- **禁止事项**：将可视化动画等同物理精确仿真。
- **前置依赖**：01-03、01-04。
- **交付物**：仿真架构、平台选型 ADR。
- **验收标准**：每种仿真模型明确输入、输出、假设和误差边界。

## 节点 07-02：虚拟 MCU 与外设模型
- **状态**：未完成
- **必须完成**：实现或集成虚拟 GPIO、定时器、PWM、ADC、串口、步进驱动、限位、温度传感器和加热负载模型。
- **禁止事项**：在仿真中伪造未建模的硬件精度。
- **前置依赖**：04-02、03-03。
- **交付物**：虚拟 HAL/外设和模型说明。
- **验收标准**：同一固件业务逻辑可连接仿真后端并执行测试。

## 节点 07-03：运动、热过程与通信仿真
- **状态**：未完成
- **必须完成**：建立轴运动、步进响应、限位触发、热惯性、温度反馈、挤出量和通信延迟/丢包模型。
- **禁止事项**：把简化模型结果当作实机精度承诺。
- **前置依赖**：02-01、05-02、05-04、06-01。
- **交付物**：可配置仿真模型和场景。
- **验收标准**：模型参数来源/假设明确，边界场景可重复。

## 节点 07-04：仿真场景与可视化
- **状态**：未完成
- **必须完成**：提供启动、连接、归零、点动、预热模拟、打印、暂停、恢复、故障注入和任务结束场景。
- **禁止事项**：只验证 happy path。
- **前置依赖**：07-02、07-03、06-04。
- **交付物**：场景库、运行脚本、可视化界面。
- **验收标准**：一条命令或明确步骤可复现所有核心场景。
